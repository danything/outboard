■ モデルの置き方
  Q1: LEVEL=1 の PMOS。KP=26.7 A/V^2、RD=31mΩ、RS=5mΩ、LAMBDA=0.01、VTO=-0.9 (typ) / -0.5 (min)
      → Rds(on) 47mΩ@-4.5V・60mΩ@-2.5V (データシート typ) に一致。gfs は 14.6 S @4A (データシート 17 S)
      外付け: Cgs 590pF、Cgd 55pF、Cds 25pF (データシート Ciss 645 / Coss 80 / Crss 55 pF @Vds=-15V)、Rg 7.8Ω
      ※ 依頼の文には Crss 約 80pF とあったが、データシート (Rev 3.1) は Coss 80pF・Crss 55pF
  SWN (Q2+Q3): 理想スイッチ 10Ω / 開放。F1: 0.2Ω の抵抗。コンデンサは理想 (ESR なし)
  場面 1: S を理想の電圧源で 0 → VIN (立ち上がり 10µs / 100µs / 1ms)。CL 100µF、負荷なし
  場面 2〜4: 12.36V の電源 → 1Ω → S、S に 44µF (20µF も試した: 差なし)
  時刻はどの場面も t = 1ms が出来事の始まり (CSV と図は そこを 0 とした)
  案: A = R15 150k / C20 1µ / C32 33n、B = 33k / 1µ / 47n、C (旧 rev B) = 100k / 100n / 47n、R14 は全部 100k
      D = A の C20 を 2.2µ に、E = R15 220k / C20 1µ / C32 22n (詰める候補。数値だけ)

■ 読み方
  ・挿した瞬間の Vgs は容量の分圧 -VIN × C32/(C20+C32) で決まる (A 3.2%、B 4.5%、C 32%)。立ち上がりの速さにはほぼよらない
  ・オンの傾きは (ゲートを引く電流)/C32、突入は (CL+10µF) × 傾き
  ・オフの遅れは R14 × C20 でゲートが抜ける時間。短絡のときも同じだけ待たされる

■ 注意 (モデルが粗い)
  ・LEVEL=1 は しきい値より下の電流 (サブスレッショルド) が 0。実物は |Vgs| < Vth でも µA〜mA が流れうる
  ・Vth の温度による動き (高温で約 -2mV/℃ ぶん小さくなる)、Rds の温度係数、自己発熱は入っていない
  ・Cgd は一定値 (実物は Vds が小さいと数倍になる)。C32 が 33nF 以上なので影響は小さい
  ・飽和の電流は実物より大きく出る (LEVEL=1 は 2 乗則のまま。データシートの -4.5V の曲線は 20A 台で寝る)
  ・電源は「12.36V + 1Ω」。本物の昇圧は 0.5A ほどで垂れるので、短絡の 9A・1.9J は上限の見積もり。
    一方で昇圧はダイオードで入力から素通しになるので、短絡の電流は入力の側 (USB の電源) の制限で決まる
  ・PTC は 0.2Ω のまま (切れない)。コンデンサの DC バイアスによる減り・ESR・配線のインダクタンスはなし
  ・2N7002 の Coss や漏れ、ゲートの保護は入っていない
