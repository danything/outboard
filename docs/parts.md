## 区分のまとめ

- **Extended は 9 種類**: USB-C、PCIe スロット、CH224A、TPS62933、MT3608B、CH32V003、4.7µH、PTC、2×5 ヘッダ
- **Preferred は 3 種類**: HT7550-1、BZT52B12、SRV05-4
- 残りは Basic

費用への効き方は [見積もり](manufacturing.md#見積もり)。

## Extended のまま残した理由

Basic (351 件) と Preferred (1,235 件) の全件から代わりを探した結果。

| 部品                             | Basic・Preferred を探した結果                                                                                                                                                                                                          |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| USB-C、PCIe スロット、ピンヘッダ | 無い (コネクタの分類そのものが無い)                                                                                                                                                                                                    |
| CH224A                           | PD のシンクは無い。CH221K・HUSB238 も Extended                                                                                                                                                                                         |
| TPS62933                         | 条件 (入力 4.2V 以下から・3A) に合うのは Preferred の TPS54331DR (C9865、3.5〜28V、3A、570kHz) だけ。非同期で外付けダイオードが要り、3A で 0.5〜1W 多く失う。SOIC-8 で基板も変わる。候補として残し、替えていない。同期整流のものは無い |
| MT3608B                          | 無い (Preferred の昇圧は TPS61040 の 0.4A と MC34063 だけ)                                                                                                                                                                             |
| CH32V003F4P6                     | Preferred に STM8S003F3P6TR (C52717、TSSOP-20) がある。ピンが違い、別の系統でファームウェアも別物になる。候補として残し、替えていない                                                                                                  |
| 4.7µH                            | 無い (Preferred の 4.7µH は信号用の 15〜25mA だけ)                                                                                                                                                                                     |
| PTC                              | 無い                                                                                                                                                                                                                                   |

## SS54 と SSL54

D1・D2 を順電圧の低い SSL54 (C41410770、Preferred) に替える案を比べ、**SS54 のままにした**。値はどちらもデータシートから。

|                                                       | SS54                                      | SSL54                                     |
| ----------------------------------------------------- | ----------------------------------------- | ----------------------------------------- |
| 順電圧                                                | 最大 0.55V (5A)。グラフ読みで 3A 約 0.42V | 最大 0.48V (5A)。グラフ読みで 3A 約 0.38V |
| 3A のときの損失                                       | 約 1.26W                                  | 約 1.14W (1 割減)                         |
| 9V・100℃ の逆電流 (typical) → 1kΩ のブリーダでの VBUS | 約 3mA → 3.0V                             | 約 4.5mA → 4.5V                           |
| 9V・75℃                                               | 約 0.2mA → 0.2V                           | グラフから読めない (SS54 より多い)        |
| RθJA・接合温度の上限                                  | 60℃/W・125℃                               | 80℃/W・150℃                               |
| 区分                                                  | Basic                                     | Preferred                                 |

順電圧の得は 3A で 0.04V ほど (グラフ読みの粗さと同じくらい) なのに、熱いときの逆電流が 1.5 倍で、
② だけつないだときに VBUS1 が 0.8V (vSafe0V) を超える温度が下がる ([入力のまとめとブリーダ](design.md#入力のまとめとブリーダ))。
SSL54 には JLCPCB (EasyEDA) のフットプリントも無い。熱は、銅を広げることで対処する ([history.md](history.md#基板で守ること))。

## F1

1206L110/16NR は、保持 1.1A・遮断 2.2A・16V。データシートの表で、保持電流は 60℃ 0.72A・70℃ 0.66A・85℃ 0.55A (使うのは 0.5A)。在庫 18,883 (2026-11-11)。

- 前に使っていた nSMD075-16V (保持 0.75A) は、熱いときの保持電流が足りないので替えた。
- 1812 の 33V 品 (C142747、C269134) も候補だったが、70℃ の保持が 0.63A でこれより低い。

## J4 を囲いなしにした理由

囲いつきは IDC 用の箱形ヘッダしか見つからなかった。マザーボードの USB ヘッダ用のプラグ (欠けピンで向きを決める) は IDC の箱の切り欠きに合う作りではないので、採っていない
(判断。実物では確かめていない)。誤挿しは 9 番ピンを抜いて防ぐ ([届いてから手ですること](manufacturing.md#届いてから手ですること))。
