## 部品の一覧

部品は全部で 121 個 (rev D の 111 個から 2×5 のヘッダを外し、ハブのための 10 個と、カードの VBUS の PTC F2 を足した。取り付け穴 H1〜H6 は数えない。rev D の KiCad のネットリストの 115 は H1〜H4 を含む)。JLCPCB が載せるのは 108 個で、残りの 13 個 (J5・JP1〜JP7・TP1〜TP5) は載せない。おもて面だけに載せる。回路でのつなぎ方は [design.md](design.md#ブロックごとの回路)。

## 区分のまとめ

- **Extended は 11 種類**: USB-C、PCIe スロット、CH224A、TPS62933、MT3608B、CH32V003、4.7µH、PTC (F1)、PTC (F2)、CH334P (ハブ)、PH のコネクタ。rev D の 2×5 ヘッダ (Extended) は外した。HT7550-1 が Extended なら 12 種類
- **Preferred は 3 種類**: HT7550-1 (2026-11-13 の部品のページは Extended の表示。見積もりの画面で確かめる)、BZT52B12、SRV05-4
- 残りは Basic

費用への効き方は [見積もり](manufacturing.md#見積もり)。

## Extended のまま残した理由

## SS54 と SSL54

D1・D2 を順電圧の低い SSL54 (C41410770、Preferred) に替える案を比べ、**SS54 のままにした**。値はどちらもデータシートから。

|                                                       | SS54                                      | SSL54                                     |
| ----------------------------------------------------- | ----------------------------------------- | ----------------------------------------- |
| 順電圧                                                | 最大 0.55V (5A)。グラフ読みで 3A 約 0.42V | 最大 0.48V (5A)。グラフ読みで 3A 約 0.38V |
| 3A のときの損失                                       | 約 1.26W                                  | 約 1.14W (1 割減)                         |
| 9V・100℃ の逆電流 (typical) → 1kΩ のブリーダでの VBUS | 約 3mA → 3.0V                             | 約 4.5mA → 4.5V                           |
| 9V・75℃                                               | 約 0.2mA → 0.2V                           | グラフから読めない (SS54 より多い)        |
| RθJA・接合温度の上限                                  | 60℃/W・125℃                               | 80℃/W・150℃                               |
| 区分                                                  | Basic                                     | Preferred                                 |

順電圧の得は 3A で 0.04V ほど (グラフ読みの粗さと同じくらい) なのに、熱いときの逆電流が 1.5 倍で、
② だけつないだときに VBUS1 が 0.8V (vSafe0V) を超える温度が下がる ([入力のまとめとブリーダ](design.md#入力のまとめとブリーダ))。
SSL54 には JLCPCB (EasyEDA) のフットプリントも無い。熱は、銅を広げることで対処する ([history.md](history.md#基板で守ること))。

## F1

1206L110/16NR は、保持 1.1A・遮断 2.2A・16V。データシートの表で、保持電流は 60℃ 0.72A・70℃ 0.66A・85℃ 0.55A (使うのは 0.5A)。在庫 18,883 (2026-11-11)。

- 前に使っていた nSMD075-16V (保持 0.75A) は、熱いときの保持電流が足りないので替えた。
- 1812 の 33V 品 (C142747、C269134) も候補だったが、70℃ の保持が 0.63A でこれより低い。

## F2

SMD0603-010-24V (TECHFUSE) は、保持 0.1A・遮断 0.3A・24V・最大 40A、0603 (1.45〜1.85 × 0.65〜1.05、厚み 1.0 以下)。抵抗は 0.9Ω (最小)〜10Ω (切れて戻ったあとの最大)。0.5A で 1 秒以内に切れる。

- 0.1〜0.2A の PTC は Basic・Preferred に無い (2026-11-13)。どれでも Extended になる。
- 候補の比べ (どれも TECHFUSE、Extended): nSMD010 (C70065、0.1A・60V・1206、在庫 98 万)、nSMD020-30V (C69680、0.2A・30V、3.5 × 1.8、抵抗 0.35〜2.7Ω)、SMD0805-010-24V (C70055)。
  置く場所 (J6 の外枠と JP3 の間) に 0805 以上が入らないので 0603 にした。抵抗が大きいぶん、50mA で最大 0.5V 下がる (カードの VBUS は検出に使うだけの見込み)。
- ランドはデータシートに無いので、0603 のチップのランド (コンデンサと同じ 0.8 × 0.9、中心の間 1.4) にした。

## Y1

12MHz・3225 で負荷容量 20pF の C9002 (X322512MSB4SI、YXC、Basic)。±10ppm・ESR 80Ω。

- 負荷容量は合っていない。CH334P の中のコンデンサは片側 約 16pF で、直列 約 8pF + 基板の浮遊容量 で 約 10pF になる見込み ([USB のデータ](design.md#usb-のデータ-ハブ))。水晶は 20pF なので数十 ppm 高く振れる見込みで、USB の許容 ±500ppm には収まる (推定)。試作で周波数を測る ([最初に測ること](bringup.md#最初に測ること))。
- 合った 12pF は Basic に無い。同じシリーズの C70565 (X322512MOB4SI、12pF) は Extended で、手数料 (3.07 ドル) が増えるので 20pF のままにした。
- 測ってずれが大きければ、C70565 (同じ 3225・4 パッドのランド) に替える。ほかの 12pF: C133337 (Yajingxin、在庫 3.4 万)、C368731 (KYX、9 千)。

## J4・J6 (カードの内部 USB のコネクタ) の比べ

カードの内部 USB の口は、白い 4 ピン・上から挿す縦型・囲いと逆挿し防止つき。写真の比べ (隣の SOIC-8 の足のピッチ 1.27mm と、本体の幅) で、**ピッチは約 1.8〜2.1mm、本体の幅は約 9mm** と読んだ (PH 4 ピンの縦型 B4B-PH-K は幅 9.8、ZH (1.5mm) なら 7.5)。だから JST PH (2.0mm) と見た (推定)。基板には同じ系統の表面実装のコネクタを 2 個置き、両端に PH のハウジング (PHR-4) が付いた市販のケーブルでつなぐ。

  安さなら Megastar (C7429691、0.06 ドル) が同じランドに載る見込みだが、PHR-4 とのはまりを保証する資料は無い。2 個で 0.5 ドルほどの差なので純正にした。
