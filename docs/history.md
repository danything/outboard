# 設計の決めごとの由来

rev A〜C のレビューと rev D の形の見直しで決めたことのうち、「いまの設計がなぜこうなっているか」の要点だけを書く。
値と計算はそれぞれの文書に置き、ここからはリンクする。基板で守る決まりの数字だけは、ここに置く。

## 回路で決めたこと

| 決めたこと                                               | 理由                                                                                                                                                                        | 詳しく                                                             |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| TVS を載せない。代わりに 20V で壊れない部品でそろえる    | 手に入る TVS は、抑える電圧が部品の定格より上で守りにならない                                                                                                               | [20V がかかったとき](design.md#20v-がかかったとき)                 |
| 過電圧の遮断 (D7・Q4)                                    | 昇圧は止めていても入力が出力へ素通しになるので、VIN が高いとき 12V の出力スイッチを入れさせない                                                                             | [過電圧の遮断](design.md#過電圧の遮断)                             |
| Q3 を Q2 に直列 (ゲート = +3V3)                          | 3.3V が無いのに 12V だけ出ることをハードで防ぐ                                                                                                                              | [12V の昇圧と出力スイッチ](design.md#12v-の昇圧と出力スイッチ)     |
| U3 の EN を VBUS1 の分圧だけで上げる                     | ② (充電器) だけでは 3.3V を出さない                                                                                                                                         | [3.3V の降圧](design.md#33v-の降圧)                                |
| F1 (PTC) を 12V の出力に入れる。保持 1.1A の品           | 短絡のときに頼るのは F1。保持 0.75A の品は熱いときの保持電流が足りなかった                                                                                                  | [F1](parts.md#f1)                                                  |
| Q1 のゲートを 150kΩ・1µF・33nF に                        | 前の値 (100kΩ・100nF・47nF) では、充電器を挿した瞬間に Q1 が入った。再レビューの案 (33kΩ・1µF・47nF) は、Vgs が −10.4V (定格 ±12V に近い) になり、突入も 0.7〜1.3A と大きい | [Q1 のゲート](design.md#q1-のゲート)                               |
| Q1 を AO3401A に (ゲートの耐圧 ±12V に合わせて分圧)      | Basic の部品にするため                                                                                                                                                      | [部品の一覧](parts.md#部品の一覧)                                  |
| ブリーダを 1kΩ、0805 を 2 直列 × 2 並列に                | 10kΩ では、75℃ のとき D1 の逆電流で VBUS1 が 2V になる。0603 では、21V のときの損失が定格を超える                                                                           | [入力のまとめとブリーダ](design.md#入力のまとめとブリーダ)         |
| D1・D2 は SS54 のまま                                    | SSL54 は順電圧の得が小さく、熱いときの逆電流が多い                                                                                                                          | [SS54 と SSL54](parts.md#ss54-と-ssl54)                            |
| PD6 → EN、PC3 → PERST# に直列 1kΩ                        | ファームウェアがまちがえて High を出したときの電流を抑える                                                                                                                  | [仕様](firmware.md#仕様) の 8                                      |
| PERST# を 15kΩ・10µF に。D6 を並列。マイコンにもつなぐ   | 3.3V が立ってから 100ms 以上遅らせ、3.3V が落ちたらすぐ下げる                                                                                                               | [5V とマイコン](design.md#5v-とマイコン)                           |
| EN の C15 を 1µF に                                      | 挿した直後のばたつきを避ける                                                                                                                                                | [3.3V の降圧](design.md#33v-の降圧)                                |
| +12V を ADC で読む (スロットの側)                        | 短絡と電圧の低下をファームウェアが見る                                                                                                                                      | [仕様](firmware.md#仕様) の 5                                      |
| CH224A の CC を入れ替えてつなぐ                          | 基板の上で 2 本を交差させない (うらを通さない)                                                                                                                              | [USB-C の入力と PD](design.md#usb-c-の入力と-pd)                   |
| U5 は IO1・IO2 だけ使う。REF は未接続                    | REF の TVS は 6V で、9V の VBUS にはつなげない                                                                                                                              | [USB のデータ](design.md#usb-のデータ)                             |
| スライドスイッチをやめて JP7 (開いたはんだジャンパー) に | ふだん切り替えるものではない。Extended の部品を減らす                                                                                                                       | [ジャンパーとテストポイント](design.md#ジャンパーとテストポイント) |
| JP5・JP6 (閉じたはんだジャンパー) を JP1・JP2 に並列     | ヘッダを載せなくても動く。電流を測るときだけ橋を切る                                                                                                                        | 同上                                                               |
| LED は 2 個 (3.3V と STAT)                               | マイコンの空きピンが少なく、PD の状態は I2C で読める                                                                                                                        | [LED の点滅](firmware.md#led-の点滅)                               |
| J4 を JLCPCB に載せてもらう                              | 自分ではんだ付けしない                                                                                                                                                      | [JLCPCB への出し方](manufacturing.md#jlcpcb-への出し方)            |
| 降圧 IC とマイコンは Extended のまま                     | 代わりは損失が増えるか、ファームウェアが別物になる                                                                                                                          | [Extended のまま残した理由](parts.md#extended-のまま残した理由)    |

## 形で決めたこと

| 決めたこと                                                      | 理由                                                             | 詳しく                                 |
| --------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------------------- |
| USB-C をブラケットと同じ側に。口の面 = ブラケットの外の面       | ケースに入れたとき、カードの端子と USB-C が同じ面に並ぶ          | [ブラケット](mechanical.md#ブラケット) |
| ブラケットの板が通る所は、基板の辺を切り欠く (1.5mm 引っ込める) | ブラケットは基板の面を越えて伸びるので、そこに基板があると当たる | [寸法](mechanical.md#寸法)             |
| LED を、カードと反対の長い辺のすぐそばに                        | カードの部品に隠れない。横向きに光る LED は安い区分に無い        | 同上                                   |
| スロットを straddle に、J4 を横向きに (rev D)                   | 基板 1 枚で、薄く、自分ではんだ付けしない                        | [形の選び方](mechanical.md#形の選び方) |

## 基板で守ること

rev A〜C のレビューで決めた、配置と配線の決まり。rev D の基板でも守る。rev D での実際の値は**未定 (段階 4 で決める)**。

| 所                         | 決まり                                                                                                                                | 理由                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| U3 (降圧)                  | VIN・GND・SW はパッドのすぐ外から銅の面にする。GND は 4 番ピンのそばにビア 4 個以上                                                   | スイッチングの電流の輪を小さくし、熱を逃がす                                   |
| U4 (昇圧)                  | GND の 2 番ピンから 2mm 以内にビア 2 個。出力のコンデンサ (C18) は D4 のカソードのすぐそば。FB の分圧はうらをくぐらせない             | 同上                                                                           |
| D1・D2                     | おもての銅の面を、アノードは各 150mm² 前後、カソード (VIN、2 個で共用) は 300mm² 前後。うらにも VIN の面を取り、ビア 6 個以上でつなぐ | 放熱。5V で大きな電流を流すと熱い ([電力の見積もり](design.md#電力の見積もり)) |
| F1                         | Q1・D4・L2 から 8mm 以上離す                                                                                                          | PTC は温まると保持電流が下がる ([F1](parts.md#f1))。熱い部品から離す           |
| CC の線                    | USB-C の殻の下を通さない (線もビアも)                                                                                                 | 殻と短絡させない                                                               |
| USB-C の GND               | パッドごとにビア 2 個                                                                                                                 |                                                                                |
| VBUS の出口                | パッドの列を出たらすぐ幅を広げて面へ                                                                                                  | 3A が通る                                                                      |
| 3.3V の道                  | 幅 1.5mm 以上 (パッドのそばの短い所は除く)                                                                                            | 3A が通る                                                                      |
| 閉じたはんだジャンパーの橋 | 幅 1.0mm                                                                                                                              | JP5 は 3.3V の 3A が通る                                                       |
| うらの面の線               | 合計 150mm 以下がめやす。降圧・昇圧・USB のデータ線の下は 0                                                                           | うらの GND を切らない                                                          |
| USB の D+ と D−            | 長さの差 0.5mm 以下                                                                                                                   |                                                                                |
| シルク                     | 部品番号を全部刷る                                                                                                                    | 試作で測る・直すため                                                           |
| 部品の外枠 (コートヤード)  | 重なり 0                                                                                                                              |                                                                                |
| J3 のまわり                | 耳の下は両面とも部品を置かない。J3 のパッドと外形 (キーの切り欠き) の間だけ 0.2mm を許し、ほかは 0.3mm                                | [スロットと座標](mechanical.md#スロットと座標)                                 |
