# 基板の検査

基板を守る検査は 3 つある。tscircuit 自身の検査 (ビルドのとき)、**自前の検査** (`checks/`。circuit.json を読む)、**KiCad の DRC** (`tools/kicad-drc.ts`。tscircuit が書き出した KiCad の基板にかける)。
tscircuit の検査は、細い線・小さいビア・取り付け穴に重なるビア・電源の線の細さを見ない。それを下の 2 つで守る。

数字は全部 [`checks/rules.ts`](../checks/rules.ts) にある。KiCad の決まり ([`tools/outboard.kicad_dru`](../tools/outboard.kicad_dru)) は同じ数字で、食い違うとテストが落ちる。

## どちらが何を守るか

| 守ること                                                             | 自前の検査                                | KiCad の DRC                   |
| -------------------------------------------------------------------- | ----------------------------------------- | ------------------------------ |
| 線幅・ビアの穴と外径と輪・穴と穴・穴と銅・銅と外形 (JLCPCB の条件)   | **主** (`fab.ts`)                         | 二重の確かめ (同じ数字)        |
| 違うネットの銅の間隔                                                 | 主 (線・パッド・ビア・面の外周と切り抜き) | **面を塗り直した形**で確かめる |
| つながっていない所・短絡・浮いた面・片側だけのビア                   | 見ない                                    | **主**                         |
| 部品のランドの中 (同じ部品のパッドどうし・穴どうし)                  | 見ない (`lib/footprints.test.ts` が持つ)  | **主**                         |
| コートヤードの重なり・シルク                                         | 見ない                                    | **主**                         |
| 取り付け穴のねじの頭の下                                             | **主** (`mountingHoleKeepout`)            | 見ない                         |
| ネットごとの線幅・電流の道すじ・ビアの数・銅の面積・部品どうしの距離 | **主** (`power.ts`)                       | 見ない                         |
| USB の長さの差・殻の下・うらの線                                     | **主** (`signal.ts`)                      | 見ない                         |
| 受け渡しの点で両側の銅がつながること                                 | **主** (`handoffs.ts`)                    | 見ない (つながりだけは見る)    |
| 部品の高さ・おもて面だけ・ブラケットと耳の下・コネクタの位置         | **主** (`mechanical.ts`)                  | 見ない                         |
| 回路の値 (分圧・定格)・rev D と同じつながり方                        | **主** (`design.ts`・`tools/netlist.ts`)  | 見ない                         |

KiCad の側で除外しているのは 3 つだけ ([`tools/kicad-drc.ts`](../tools/kicad-drc.ts)):
`lib_footprint_issues` (書き出しが `tscircuit` という無いライブラリを名指す) とだけ。未接続 (`unconnected_items`)・ぶら下がり (`track_dangling`) を含め、ほかは全部落ちる。
閉じたはんだジャンパー (JP3〜JP6) の銅の橋は、書き出したあとで KiCad のネットタイ (`net_tie_pad_groups`) にする ([`tools/kicad-nettie.ts`](../tools/kicad-nettie.ts)。`bun run build` の続き)。自前の検査は、部品が結ぶピン (`tiedPins`) の 2 つのネットを 1 つとして見る (名前は短いほう、主の電源の名前)。
J3 のパッドとキーの切り欠きの 0.2mm は、除外ではなく KiCad の決まりの側で許している。

配線のある基板を書き出して確かめたこと: ネット・線・ビア・面は KiCad に渡る。シルクの文字の高さ (`text_height`) と重なり (`silk_overlap`) は、部品番号の文字を出すと指摘される見込み。

## 自前の検査の一覧

「いま」は、いまの基板で効いているか。全部の検査が効く。`bun run check` は `bun checks/run.ts --strict` で、指摘か飛ばしが 1 つでもあると落ちる (CI とリリースも同じ)。配線を試すときは `bun checks/run.ts` (--strict なし) で、配線に頼る指摘を `(open)` と出して先へ進める。

| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `boardSize`           | 100 × 100mm 以内、厚み 1.6mm                                                                                                                                                                               | 効く |
| `mountingHoleCount`   | M3 の穴が 4 個以上                                                                                                                                                                                         | 効く |
| `trackWidth`          | 線幅 0.15mm 以上                                                                                                                                                                                           | 効く |
| `viaSize`             | ビアの穴 0.3・外径 0.6・輪 0.15 以上                                                                                                                                                                       | 効く |
| `padRing`             | スルーホールの輪                                                                                                                                                                                           | 効く |
| `clearance`           | 違うネットの銅の間隔 0.15                                                                                                                                                                                  | 効く |
| `holeSpacing`         | 穴と穴 0.5                                                                                                                                                                                                 | 効く |
| `holeToCopper`        | 穴とほかのネットの銅 0.3。めっきなしの穴はどの銅とも 0.3                                                                                                                                                   | 効く |
| `mountingHoleKeepout` | 取り付け穴の縁から 1.4 の中に線・ビア・パッドが無い                                                                                                                                                        | 効く |
| `edgeClearance`       | 銅と外形 0.3 (J3 だけ 0.2)                                                                                                                                                                                 | 効く |
| `ruleTargets`         | 決まりの表が名指すパッドが基板にあり、そのネットにある                                                                                                                                                     | 効く |
| `netWidth`            | 電源と GND の線は 0.3 以上 (同じネットの面の中と、細いパッドに着く線は除く)                                                                                                                                | 効く |
| `powerPaths`          | 電流の道すじの「いちばん太い道のいちばん細い所」。線とパッドで測り、さらに面を含む銅を 0.05mm の格子に描いて面の首も測る。パッドから 2.6mm 以内の首はパッドの幅まで可                                      | 効く |

| `fuseDistance`        | F1 が Q1・D4・L2 から 8mm 以上                                                                                                                                                                             | 効く |
| `boostLoop`           | D4 のカソードから C18 まで 4mm 以下、C18 の GND から U4 の GND まで 3.5mm 以下                                                                                                                             | 効く |
| `usbPair`             | D+ と D− の長さの差 0.5mm 以下、うらを通るのは 2.6mm まで                                                                                                                                                  | 効く |
| `underShell`          | USB-C の殻の下に CC の線とビアが無い                                                                                                                                                                       | 効く |
| `bottomUnder`         | 降圧・昇圧・USB の線の下のうらに線が無い。FB はおもてだけ。例外は J1_CC1 の 1 本 (U1 の北、4.2mm まで。`USB_BOTTOM_CROSSINGS`)                                                                             | 効く |
| `bottomTotal`         | うらの線の合計 500mm 以下 (めやすは 150)                                                                                                                                                                   | 効く |
| `partsOnTop`          | 部品は全部おもて                                                                                                                                                                                           | 効く |

| `connectorPosition`   | USB-C が x = 4.08、間隔 15 以上、J3 の 1 番ピンが x = 46.55                                                                                                                                                | 効く |
| `handoffs`            | `HANDOFFS` の点ごとに、両側の銅がその層で点に届いてつながり、幅が表の幅以上                                                                                                                                | 効く |

## rev D の check_board.py から移さなかったもの

| 検査                                                      | 理由                                                                              |
| --------------------------------------------------------- | --------------------------------------------------------------------------------- |
| U3 の VIN・GND・SW が「パッドのすぐ外から面」             | 面の名前と決め打ちの座標に頼っていた。`powerPaths` (面か 1.5mm 以上) に置き換えた |
| JP5 の橋の幅 1.0mm                                        | 橋はランドの中の pin 1 のパッド。幅は `lib/footprints.test.ts` が見る             |
| 銅の抵抗の記録、ケースの厚みの記録、VIN の帯をくぐる線    | 記録だけで、合否が無かった                                                        |
| J3 の列の面・パッドの大きさ・耳の穴・キーの切り欠き       | `lib/footprints.test.ts` と外形 (`lib/geometry.ts`) が持つ                        |
| J3 のおもてとうらのパッドのつながり、USB の裏返しのパッド | KiCad の DRC の「つながっていない所」が見る                                       |
| J3 の GND を面に頼らず線でビアへ                          | 面の塗りの形が KiCad と違うため保留。KiCad の DRC の「浮いた面」が近いものを見る  |
| LED の位置、J4 のプラグの下、取り付け穴の位置、シルク     | rev D の配置の座標に頼っていた。配置が決まったら `KEEP_OUT` (rules.ts) に足す     |
| シルクの線の太さ・部品番号が全部出ている                  | tscircuit の書き出しにシルクの文字が無い。出すようになったら KiCad の DRC が見る  |

## rev D の check_netlist.py から足したもの・移さなかったもの

回路の担当の `checks/design.ts` (14 個) に無かったものを 5 個足した: `vbusCapacitance` (VBUS の容量 1〜10µF)、`buckInputCapacitance` (降圧の入力の容量)、
`overVoltageWindow` (過電圧の遮断が 14V 未満で確実に切れる・15V でベース電流が足りる・そのときの Q1 の Vgs)、`ccSeries` (CC の直列抵抗の電流)、`perstDelay` (PERST# の遅れ 100ms 以上)。

移さなかったもの: 過電圧の遮断の下のしきい値 (ツェナーの電圧だけで決まり、circuit.json に値が無い)、F1 の保持電流と耐圧 (同じ。品番の比べが守る)、
つながりだけの検査 (rev D とのネットリストの比べが守る)。
