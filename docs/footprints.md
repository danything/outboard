# フットプリント

全部品のランド (`lib/footprints.ts`) を、メーカーのデータシートの推奨ランドと突き合わせた結果と、ランドのデータの出どころを書く。
**実物の部品を載せて確かめたものは無い** (試作前)。数字はデータシートの図を読んだものである。

## 決まり

- 単位は mm。原点は部品の中心、x は右、y は上 (tscircuit の向き)。
- **向き (どちらが 1 番か) は EasyEDA (JLCPCB のライブラリ) の同じ品番のフットプリントに合わせてある。** 配置表の回転が JLCPCB の側と同じ意味になるようにするため。J3 だけは例外 (下)。
- パッドの番号は rev D の KiCad のライブラリと同じ。回路のつながりの検査 (段階 2) は、この番号で比べる。
- パッドの大きさと位置は、メーカーの推奨ランドがあればそれに合わせる。合わせた数字は `lib/footprints.test.ts` が検査していて、ランドを変えると検査も変えることになる。
- 絵は [`__snapshots__/footprints.circuit-pcb.snap.svg`](../__snapshots__/footprints.circuit-pcb.snap.svg) (おもて) と [`footprints.circuit-bottom.snap.svg`](../__snapshots__/footprints.circuit-bottom.snap.svg) (うら。J3 の A 列)。

## 突き合わせの表

判定: **合わせた** = 推奨の数字にした / **合う** = EasyEDA 由来のままで推奨と同じ / **差は小さい** = 推奨と少し違うが、そのままにした (理由つき) / **推奨なし** = データシートに推奨ランドが無い / **未照合**。

### 極性とピンの対応

データシートで確かめたもの: Q1 (1 = G、2 = S、3 = D)、Q2・Q3 (1 = G、2 = S、3 = D)、Q4 (1 = B、2 = E、3 = C)、LED (1 = アノード)。

**ダイオードの 1 番がどちらかは、データシートからは決まらない** (帯の側がカソード、とあるだけで番号が無い)。
EasyEDA の記号とフットプリントの対応に従っている: D1・D2 (SS54) は 1 番がアノード、D4 (SS34)・D5・D6・D7 は 1 番がカソード。
シルクの点はカソードの側に打つ。**発注の画面の配置の絵で、帯の向きを確かめる** ([manufacturing.md](manufacturing.md))。

## データの出どころと利用条件

- ランドの数字のもとは 2 つ: **EasyEDA / LCSC のライブラリ** (rev C・rev D の KiCad のライブラリが easyeda2kicad で取り込んだもの。向きと、推奨ランドの無い部品のパッド) と、**各メーカーのデータシート** (上の表)。`lib/footprints.ts` は、それらの数字を読んで書き直したデータで、EasyEDA のファイルそのものは入っていない。
- TP・はんだジャンパー・取り付け穴の寸法は KiCad の標準ライブラリと同じ値。
- 3D のモデルは入れていない。
- **EasyEDA / LCSC のライブラリの利用条件は未確認。** 公開のリポジトリに EasyEDA 由来のファイルをそのまま置くことはしていないが、数字 (パッドの寸法) は使っている。
- データシートの PDF はリポジトリに入れない。
