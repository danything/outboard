# 製造

outboard (rev D) を JLCPCB に出すときの設定、見積もり、見積もりの画面で確かめる所、届いてから手ですることを書く。
**発注はまだしていない。** 料金は 2026-11-12 に料金のページと見積もりの API で取った値。部品を入れた実装の見積もりは取っていないので、**合計は見積もりの画面で確かめるまで概算**である。
**はんだ付けは全部 JLCPCB に頼む** (自分では付けない)。

出すファイル (ガーバー・BOM・配置) を tscircuit から作る手順は、後の段階で足す。

## JLCPCB への出し方

0. **発注の前に、ガーバー・BOM・CPL (配置) をサポートに送って engineering evaluation を頼む。** J3 の手はんだの追加料金と、端から出る部品のための治具が要るかとその費用は、この審査で決まる
1. 基板: 2 層、1.6mm、銅 1oz、ほかは標準。外形は [寸法](mechanical.md#寸法) (後ろの辺に 1.5mm の段、J3 の所にキーの切り欠きがある。入り隅は工具の丸みになる)
2. 「PCB Assembly」をオン。**Economic**、Top Side、数量 2。
   備考欄に「J1/J2 (USB-C) overhang the board edge by 1 mm」と書く (基板の端から部品が出ることを先に伝える)
3. BOM と配置のファイルを上げる
4. 部品の割り当ての画面で、全部の行が LCSC の品番で見つかること、在庫、Basic / Extended の区分を確かめる ([部品の一覧](parts.md#部品の一覧))
5. **部品の配置の絵で向きを確かめる。** ずれていたらその場で回す

JLCPCB が付ける物: 表面実装の部品全部 (カードの内部 USB の J4・J6 も表面実装でリフロー)。手はんだは J3 だけで、表と裏の両方の列 (18 + 18) を付ける。

載せない物:

- TP1〜TP5、H1〜H4
- はんだジャンパー JP3・JP4・JP5・JP6 (幅 1.0mm の銅の橋で最初からつながっている) と JP7 (最初は開いている)
- 1×2 のピンヘッダ J5・JP1・JP2 (穴だけ作る)

## 見積もりの画面で見る所

部品検索では確かめられず、見積もりの画面でしか分からないこと。

- **シルクは両面** (部品番号はうら。`lib/refdes.tsx`)。見積もりの画面と能力の表 (2026-11-12) には、うらのシルクの追加料金の記述が無い。かからない見込みだが、見積もりの画面で確かめる。文字は高さ 1.0mm・線 0.15mm (JLCPCB の下限と同じ)
- **ハンダマスクの開口がパッドと同じ大きさ** (はみ出し 0。tscircuit の書き出し)。U3 と USB-C の足の間のマスクの橋は 0.2mm。JLCPCB の既定の広げ方 (0.05 前後) で作ってよいかを審査で聞く
- **ステンシル (ペーストの開口) は `tools/paste.ts` の 1 か所で決める** (検査 `solderPaste` が見る)。厚み 0.12mm (JLCPCB の既定) と見て、開口は面積比 (開口の面積 / 壁の面積) 0.66 以上:
  - ふつうはパッドと 1:1。細いピッチの U8・U3 は縦横 90% (面積比 0.74〜0.78)。PH の J4・J6 は信号も補強の足も 1:1
  - 大きなパッドは減らす: SMA のダイオードとコイルは縦横 90%、SOT-89 のタブは 85%、U1・U2 の底の板は 4 つの窓で 61%
  - U8 の底の板は、穴を避けた 4 つの窓 (0.55 × 0.75、合わせて 57%、穴の縁から 0.15 離す)。穴の上には置かない
  - J3 (両面とも手はんだ) と、USB-C の殻の足のうらには置かない (うらのステンシルは無い)
  - 厚みが 0.12 でない (0.10 など) なら、面積比はそのぶん良くなる。0.15 なら U8・U3 の足が 0.6 前後になるので、0.12 以下を頼む
- ガーバーの zip には、ガーバーとドリルだけが入る (tsci が入れる `pick_and_place.csv`・`bom.csv` は `tools/fab.ts` で外し、release でも確かめる)。上げる BOM と配置は、リリースの `*-bom.csv` と `*-cpl.csv`
- 間隔のいちばん狭い所は 0.150mm (V12_BOOST の線と Q1 のゲートのパッド)。ほかに 0.15〜0.2 の所が数か所 (VBUS1 の継ぎ目と U5、USB_DP のビアと USB_DN、OVP_B と R35、V12 と JP2.1、C6 と I2C2 の 0.155、C7 の東の 5V・I2C2・VBUS1_SENSE・CC1 の並び)。JLCPCB の下限 (0.1) より広い
- mcu の中の 0.15mm ちょうどの所 (約 10 か所): CC1_SENSE と VBUS1_SENSE、I2C2 の SCL と SDA の並び、I2C2_SCL と V5、I2C2_SCL と C6、C7 の東の GND と V5、I2C1 どうし (0.157)

- **J3 の手はんだの追加料金と、治具 (assembly fixture / carrier) が要るか。** どちらも発注の前の審査で決まる ([J3 の注意](#j3-基板の端をはさむスロット-の注意))
- **USB-C (C165948)・PH のコネクタ (C265332)・CH334P (C5373042) が Economic で載せられるか。** 部品検索には Economic / Standard の区分の欄が無かった
- **U8 (CH334P) の底の板に開けた 2 個の穴 (ø0.3、めっきあり) にはんだが吸われないか。** 底の板が唯一の GND で、四方を足に囲まれて線を外へ出せないため、板の中に穴を開けてうらの GND へつないだ ([footprints.md](footprints.md#ch334p-と水晶))。ペーストは穴を避けて置いた (上)。**うらのマスクで穴を閉じる (tenting) か、穴をふさぐ (樹脂の充填・via-in-pad) か、そのままでよいかを JLCPCB に聞く** (tscircuit の書き出しでは、穴のうらはマスクが開いている)
- **U6・U9 (HT7550-1、C16106) の区分**: 11-12 の読みは Preferred、11-13 の部品のページは Extended の表示。Extended なら手数料が 1 種ぶん増える
- **J3 が配置の絵で裏返しに見えないか。** JLCPCB (EasyEDA) のフットプリントは J3 のデータシートと 2 か所食い違っていて、この設計はデータシートに合わせてある:
  (1) EasyEDA は耳の所の基板を切り欠いている (データシートは辺がまっすぐで、耳の穴が基板に開く)、
  (2) EasyEDA は「口を上・1 番を左」に見た面に A 列を置いている (データシートの推奨の基板は同じ向きで B 列)
- **基板の厚みと J3 のすき間。** J3 は 1.57mm の基板用 ([スロットと座標](mechanical.md#スロットと座標))
- **スルーホールの部品 (J3) に Extended の手数料がかからないこと。** 公式のブログ (<https://jlcpcb.com/blog/reduce-pcb-assembly-cost-prototype>、2026-10-14) はかからないと書いている。下の見積もりの合計は、かかるものとして数えている
- **部品の本体と基板の端の間隔。** 基板の端から出る部品 (J3 約 8mm、USB-C 約 1mm) があると、Economic でも実装と運搬のための治具が要る場合がある。要るかと費用は審査で決まる
- 5 枚のうち 2 枚だけ実装すると、残りの生基板にもはんだが付くことがある
- **配置の絵で向きを見る部品**: tsci が JLCPCB の向きを確かめられなかった D6・U5・C31・J4・J3。原点の考え方の違いで 0.12mm と 0.45mm の差がある D6・U5・LED3・LED5・J1・J2・U6。ハブで足した U8・Y1・J6・U9 (1 番ピンと向き)
- **J4・J6 は KiCad のフットプリントから起こしていて、EasyEDA の向きと違うかもしれない** (`lib/footprints.ts` の `PH4_SIDE_ENTRY`)。180° 違うと口が基板の内側を向く。**JLCPCB の DFM の画面 (配置の絵) で、口がカードの側の辺 (外) を向いていることを必ず見る**。違えばその場で回す
- 実装の最小の枚数 (部品検索の値は、見た部品では 2)
- **ダイオード・LED・ツェナーの極性、SOT-23 のピンの並び、IC の 1 番ピン。** 部品の向きは JLCPCB (EasyEDA) のシンボルとフットプリントを信じていて、確かめていない。
  部品ごとの「正しい向き」の表は、配置が決まってから書く (未定。段階 4 で決める)

## 届いてから手ですること

- カードと J4・J6 を、両端 PH 4 ピンのケーブル (**25cm、同じ向き、1 番 → 1 番**。LCSC の特注を基板と同じ荷で頼むのが第一の候補) 2 本でつなぐ ([ケーブル](mechanical.md#寸法))。逆向き (1 → 4) のケーブルは VBUS と GND が入れ替わるので使わない
- J5 (SWIO・GND) に 2 ピンのヘッダを付けるか、書き込みのときだけ線を当てる
- 電流を測るときだけ (任意): JP5 (3.3V) か JP6 (12V) の橋をカッターで切り、JP1 か JP2 の 2 つの穴に電流計のプローブを当てる。測らないなら何もしない
- 12V を手で強制オンにしたいとき (任意。はんだ付けが要る。ふだんは使わない): JP7 をはんだでつなぐ ([ファームウェアの仕様](firmware.md#仕様))
- ファームウェアを書き込む (マイコンが空のあいだ、12V は出ない)

## J3 (基板の端をはさむスロット) の注意

- **J3 (C21263091) は、表と裏の両方の列 (18 + 18) を JLCPCB が手はんだで付ける** (2026-11-12 にサポートが回答)。追加料金がかかることがあり、額は審査しだい。
  部品のページの「Wave Soldering / Economic and Standard」の表示は誤りだった (サポートが認めた)
- 横向きのスロットに替える案は不要になった
- キーの両隣の端子 (A11/B11・A12/B12) と切り欠きの間は 0.20mm (メーカーの推奨ランドどおり)。JLCPCB の確認 (DFM) で指摘されたら、切り欠きの側を 0.05〜0.1 広げる。
- 配置表 (CPL) の座標は、フットプリントの原点 (置いた位置) を出している。パッドの外接箱の中心ではない (SOT-89 と USB-C で 0.1〜0.4mm 違う)。

## ケース (JLC3DP)

ケース (皿・ふた・ハッチ) は、JLCPCB の 3D プリントの窓口 JLC3DP に、**基板とは別の注文**で出す。形は [mechanical.md](mechanical.md#ケース)。
**カードの寸法は写真からの推定**なので、実物を測って `case/card.ts` を直してから出す ([実物で測る所](mechanical.md#実物で測る所))。

出し方:

1. CI の成果物 `case` (または Pages の `case/`) から `tray.step`・`lid.step`・`hatch.step` を取る (STL も同じ所にある)。留め方やねじを変えるときは、手元で `bun run case -- --latch snap --fastener nut` のように作る
2. JLC3DP で 3 つのファイルを上げる。材料は **Resin → 9600 Resin** (SLA。熱変形温度 56〜59℃)。数量は各 1
3. 見積もりの画面で、寸法 (皿と ふた 145.5 × 151.0 × 19.4、ハッチ 95 × 60 × 3) が合っていることと、薄い所 (受けの磁石のポケットの底 0.9) の指摘が無いかを見る

費用 (持ち主の見積もり。2026-11):

| 項目 | ドル (概算) | 中身                                                       |
| ---- | ----------- | ---------------------------------------------------------- |
| 樹脂 | 約 8.7      | 9600 で 1 台ぶん (皿・ふた・ハッチ。樹脂の量は 約 121 cm³) |
| 送料 | 約 7〜9     | OCS                                                        |
| 割引 | −10         | 新規の 10 ドル券                                           |

- **基板とは別の注文にする。** 輸入の課税がかからない線 (商品代 1 万円) を、注文ごとに管理しやすい
- 3D プリントは 1 台だけでよい (寸法を確かめてから作り直す見込み)

届いてから用意する物:

- M3 のねじ: 基板 6 本・カード 2 本・ふた 3 本。長さは `insert` (既定) なら基板とカードは 6、ふたは 6。`nut` なら基板とカードは 8、ふたは 20 (ナットに掛かるのは約 1mm。足りなければ 22)
- `insert` なら M3 の真鍮のインサート 11 個 (台座 8・柱 3)。9600 ははんだごてで溶かし込みにくい見込みなので、接着 (エポキシ) する。外径が φ4.0 の穴と違えば `M3.insertHole` を直して作り直す。`nut` なら M3 のナット 11 個
- F 端子のナット 2 個 (7/16 インチの六角。カードに付いていなければ買う)
- `magnet` (既定) なら φ6 × 2 の磁石 4 個。受けとハッチで向き (極) をそろえて引き合うように入れる
- PH 4 ピンのケーブル 25cm 2 本 (同じ向き)
