# 製造

outboard (rev D) を JLCPCB に出すときの設定、見積もり、見積もりの画面で確かめる所、届いてから手ですることを書く。
**発注はまだしていない。** 料金は 2026-10-22 更新の料金のページの値で、合計は概算である。

出すファイル (ガーバー・BOM・配置) を tscircuit から作る手順は、後の段階で足す。

## JLCPCB への出し方

1. 基板: 2 層、1.6mm、銅 1oz、ほかは標準。外形は [寸法](mechanical.md#寸法) (後ろの辺に 1.5mm の段、J3 の所にキーの切り欠きがある。入り隅は工具の丸みになる)
2. 「PCB Assembly」をオン。**Economic**、Top Side、数量 2。
   備考欄に「J1/J2 (USB-C) overhang the board edge by 1 mm」と書く (基板の端から部品が出ることを先に伝える)
3. BOM と配置のファイルを上げる
4. 部品の割り当ての画面で、全部の行が LCSC の品番で見つかること、在庫、Basic / Extended の区分を確かめる ([部品の一覧](parts.md#部品の一覧))
5. **部品の配置の絵で向きを確かめる。** ずれていたらその場で回す

JLCPCB が付ける物: 表面実装の部品全部 (J3 を含む) と、スルーホールの J4 (2×5 のピンヘッダ)。

載せない物:

- TP1〜TP5、H1〜H4
- はんだジャンパー JP3・JP4・JP5・JP6 (幅 1.0mm の銅の橋で最初からつながっている) と JP7 (最初は開いている)
- 1×2 のピンヘッダ J5・JP1・JP2 (穴だけ作る)

## 見積もりの画面で見る所

部品検索では確かめられず、見積もりの画面でしか分からないこと。

- **J3 (C21263091、straddle の PCIe スロット) を JLCPCB が載せるか。** 基板の端をまたぎ、おもてとうらの両方にパッドがある。
  載せられないときは、J3 だけ自分で付ける (片面 18 パッド × 2)
- **J3・J4 (C492433)・USB-C (C165948) が Economic で載せられるか。** 部品検索には Economic / Standard の区分の欄が無かった。
  両面のはんだ付けなどで「Standard only」と出たら、費用が大きく変わる (下の見積もり)
- **J3 が配置の絵で裏返しに見えないか。** JLCPCB (EasyEDA) のフットプリントは J3 のデータシートと 2 か所食い違っていて、この設計はデータシートに合わせてある:
  (1) EasyEDA は耳の所の基板を切り欠いている (データシートは辺がまっすぐで、耳の穴が基板に開く)、
  (2) EasyEDA は「口を上・1 番を左」に見た面に A 列を置いている (データシートの推奨の基板は同じ向きで B 列)
- **基板の厚みと J3 のすき間。** J3 は 1.57mm の基板用 ([スロットと座標](mechanical.md#スロットと座標))
- **スルーホールの部品 (J4) に Extended の手数料 (Feeder Loading) がかかるか。** 料金のページは「ピックアンドプレースのフィーダーの段取りの手数料」と説明していて、
  手はんだの部品にかかるとも、かからないとも書いていない。下の見積もりは、かかるものとして数えている
- 実装の最小の枚数 (部品検索の値は、見た部品では 2)
- **ダイオード・LED・ツェナーの極性、SOT-23 のピンの並び、IC の 1 番ピン。** 部品の向きは JLCPCB (EasyEDA) のシンボルとフットプリントを信じていて、確かめていない。
  部品ごとの「正しい向き」の表は、配置が決まってから書く (未定。段階 4 で決める)

## 見積もり

実装 2 枚・基板 5 枚のとき。基板の代金・送料・税は別。

料金は <https://jlcpcb.com/help/article/pcb-assembly-price> (2026-10-22 更新) の値:

| 項目                                  | Economic                   | Standard                                                                          |
| ------------------------------------- | -------------------------- | --------------------------------------------------------------------------------- |
| 段取り (Setup)                        | 8.18                       | 25.56                                                                             |
| ステンシル                            | 1.53                       | 8.21 (片面)                                                                       |
| 部品の段取りの手数料 (Feeder Loading) | Extended 1 種類ごとに 3.07 | 全部の種類に 1 種類ごと 1.53 (Basic にもかかる)                                   |
| 手はんだ (スルーホール)               | 3.58 + 1 か所 0.0164       | 同じ                                                                              |
| Standard だけの費用                   | —                          | 取り扱い 14.93 以上 + 梱包 0.5 + 1 枚ずつの実装 0.48。治具 (16.42) が要るかは不明 |

- 「Extended 1 種類ごとに 3.07 ドル」とは料金のページに明記が無く、そう読んでいる。Preferred に手数料がかからないのは FAQ の記述から。
- Extended は 9 種類 ([区分のまとめ](parts.md#区分のまとめ)) なので、Economic の手数料は 3.07 × 9 = 27.63 ドル。

|                                              | 合計 (概算)      |
| -------------------------------------------- | ---------------- |
| **Economic で全部載る場合**                  | **約 54 ドル**   |
| 両面のはんだ付けなどで Standard になった場合 | 約 120〜140 ドル |

内訳 (部品代・はんだの点数) は、BOM が決まってから書く (未定。段階 4 で決める)。

形ごとの比べ (実装 2 枚。基板代・送料は別):

| 形                            | 見積もり                                       |
| ----------------------------- | ---------------------------------------------- |
| 2 枚・手はんだ                | 約 48 ドル + スロット基板 + スロットを別に買う |
| 2 枚・コネクタの対            | 約 74 ドル                                     |
| 1 枚・横向きスルーホール      | 約 58 ドル                                     |
| **1 枚・straddle (採った形)** | **約 54 ドル**                                 |

形を選んだ理由は [形の選び方](mechanical.md#形の選び方)。

## 届いてから手ですること

- **J4 の 9 番ピンを抜く。** マザーボードのヘッダと同じ、誤挿し防止の欠けピンにするため
- カードのケーブルが 1 列 5 ピンのときは、**奇数の列 (1・3・5・7・9)** に挿す。1 が 5V、3 が D−、5 が D+、7 が GND
- J5 (SWIO・GND) に 2 ピンのヘッダを付けるか、書き込みのときだけ線を当てる
- 電流を測るときだけ: JP5 (3.3V) か JP6 (12V) の橋をカッターで切り、JP1 か JP2 にヘッダを付けて電流計を挟む。測らないなら何もしない
- 12V を手で強制オンにしたいとき: JP7 をはんだでつなぐ ([ファームウェアの仕様](firmware.md#仕様))
- ファームウェアを書き込む (マイコンが空のあいだ、12V は出ない)
