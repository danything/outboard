# ファームウェア

outboard のマイコン (U7、CH32V003F4P6) のファームウェアが最低限やること (仕様)、ピンの割り当て、LED の点滅の意味を書く。
**ファームウェアはまだ無い。** ここにあるのは、回路の側から決まる決まりごとである。

## マイコンのピン

CH32V003F4P6、TSSOP20。電源は +5V (5V 入力のときは 4.2〜4.4V になる見込み)。

| ピン | 名前     | つなぐ先                                    |     | ピン | 名前    | つなぐ先                                                        |
| ---- | -------- | ------------------------------------------- | --- | ---- | ------- | --------------------------------------------------------------- |
| 1    | PD4/A7   | VIN_SENSE                                   |     | 11   | PC1/SDA | U1 の SDA                                                       |
| 2    | PD5/A5   | VBUS1_SENSE                                 |     | 12   | PC2/SCL | U1 の SCL                                                       |
| 3    | PD6/A6   | CC1_SENSE                                   |     | 13   | PC3     | R38 1kΩ → EN_3V3 (Low に引くか Hi-Z)                            |
| 4    | PD7/NRST | 未接続                                      |     | 14   | PC4     | R37 1kΩ → PERST# (Low に引くか Hi-Z)                            |
| 5    | PA1/A1   | CC2_SENSE                                   |     | 15   | PC5     | U2 の SCL (I2C1 を付け替え)                                     |
| 6    | PA2/A0   | 12V_SENSE                                   |     | 16   | PC6     | U2 の SDA                                                       |
| 7    | VSS      | GND                                         |     | 17   | PC7     | 未接続                                                          |

ADC の倍率と、それぞれの線の回路は [design.md](design.md#5v-とマイコン)。書き込みは J5 (SWIO・GND) から。

## 仕様

1. I2C のピン (PC1/PC2・PC5/PC6) は必ずオープンドレイン。プッシュプルで High を出さない (CH224A の中のプルアップに任せる)
2. **I2C のペリフェラルは 1 つ (I2C1) だけ。** U1 と話すときは PC1/PC2、U2 と話すときは PC5/PC6 に付け替える (AFIO の I2C1_RM)。
   付け替える前に、いま使っていない側のピンを入力 (Hi-Z) に戻す。2 つの IC は同じアドレスなので、同時にはつながない
3. CH224A のレジスタ 0x0A に、9V より上 (2 以上) を書かない。**これが、動いている最中の過電圧からカードを守る唯一の手段**
   (ハードの遮断は間に合わない。[過電圧の遮断](design.md#過電圧の遮断))
4. VIN_SENSE が 12.0V を超えたら 12V を入れない。入っていたら SW12_ON と EN_12V を下げる
   (短絡でないとき。負荷の電流は小さいので、Q1 が切れるまでの 約 0.2 秒は熱の問題にならない)
5. **12V を入れる順 (必須)**: EN_12V を上げ、VIN_SENSE と時間で昇圧が立ったと見てから SW12_ON を上げる。昇圧が止まったまま SW12_ON を上げない
   (5V 入力では昇圧の出力に VIN が素通しで 約 4.6V しか無く、Q1 の Vgs が −1.84V で半端にオンする)。

   **12V の短絡を見たとき** (+12V の ADC が上がらない・落ちる): 昇圧は D4 で入力から出力へ素通しなので、EN_12V を下げても短絡の電流は止まらない。
   電流が流れているまま SW12_ON を下げると、Q1 が線形の状態を数十 ms 通って危ない。
   → **Q1 は入れたままにして、F1 (と電源の側の保護) に任せる。+12V の電流が落ちた (F1 が切れた、または VIN が落ちた) のを VIN_SENSE・12V_SENSE で見てから、
   SW12_ON と EN_12V を下げる。そのあと一定の時間 (例: 10 秒) は 12V を入れ直さない**

6. **3.3V が落ちたら (EN_3V3 を下げるとき・VBUS1 が無くなったとき)、先に 12V を切る**
   (EN_12V と SW12_ON を下げ、+12V の ADC が下がってから 3.3V を切る)。入れる順は 3.3V → 12V
7. 電力が足りると分かるまで EN_3V3 を Low に押さえる。PD の相手は CH224A の I2C の状態と電流から、PD でない相手だけ CC の電圧から判断する
8. **PC3 (EN_3V3) と PC4 (PERST#) は、Low を出すか Hi-Z (入力) にするかの 2 通りだけ。** プッシュプルの High は決して出さない
   (PC3 は 5V で、U3 の EN の推奨 5.5V に近く、PC4 は 5V を 3.3V の PERST# に押し込む。直列の 1kΩ は、まちがえたときの電流を抑えるだけ)
9. ADC は中の基準電圧 (Vrefint) で補正する (5V 入力では VDD が下がる)
10. スタンバイは使わない
11. PERST# は、3.3V と 12V が立ってから 100ms 後に離す (それまで PC4 で Low に押さえる。ハードの遅れは 約 140ms)
12. 5V 入力では 12V の電流を抑える (値は、試作で U4 の温度を測ってから決める)

JP7 をはんだでつなぐと SW1_IN が Low になる。これを「12V を強制オン」と読む。

## LED の点滅

LED3 は +3V3 につながっていて、3.3V が出ていればハードで光る (ファームウェアは関わらない)。

LED5 (STAT、PD0) の点滅の案:

| 光り方 | 意味                                    |
| ------ | --------------------------------------- |
| 点灯   | 正常                                    |
| 1 回   | 電力不足で 3.3V を入れていない          |
| 2 回   | 12V を止めた (過電圧・短絡・電圧の低下) |
| 3 回   | PD の交渉に失敗 (9V が取れず 5V)        |
| 4 回   | JP7 で 12V を強制オン中                 |
