# 試作の立ち上げ

outboard の試作が届いたときに最初に測ること、試験の一覧、まだ確かめていないことを書く。
**実機では何も確かめていない。** 「期待」の列は設計の値 (計算・データシート・シミュレーション) で、測った値ではない。

## 発注の前に

実物のカードで寸法を測る ([実物で測る所](mechanical.md#実物で測る所))。見積もりの画面で確かめることは [manufacturing.md](manufacturing.md#見積もりの画面で見る所)。

## 最初に測ること

カードを挿す前に、カードなしで順に見る。

1. ② だけをつなぐ: 3.3V も 12V も出ないこと
2. ① をつなぐ: 3.3V が出ること (LED3 が光る)。マイコンが空のあいだは 12V が出ないこと
3. ファームウェアを書き込む (J5)。12V が出ること、PERST# が遅れて上がること
4. 充電器を挿した瞬間に +12V の線が動かないこと
5. ここまで通ってから、カードを挿す
6. **カードをつないだ状態で、J4 の VBUS の電流と、U6 の出力 (+5V、TP4) の電圧と温度を測る。** 50mA を超えたら (U6 は 100mA・SOT-89 で 約 200℃/W)、マイコンの動作と U6 の温度を続けて見る。足りなければ rev E で J4 の VBUS を別の電源 (例: VIN からの専用の 5V) から取る

測る点は TP1 (VIN)・TP2 (+3V3)・TP3 (+12V)・TP4 (+5V)・TP5 (GND)。電流は JP1・JP2 で測る ([届いてから手ですること](manufacturing.md#届いてから手ですること))。

## 確かめていないこと

回路について、計算やデータシートの読みだけで決めている所。試作で分かる。

- 実際の電気的な動作、発熱、PD の相手ごとの振る舞いは、何も確かめていない
- **D1・D2 の熱**: 熱抵抗は計算できていない。5V・3A は危ない見込み
- **CH224A の CC の入れ替え**は、データシートの記述からの判断
- **CH224A**: DP/DM を浮かせてよいか、PG を浮かせてよいか、I2C のプルアップの電圧は、データシートに書かれていない
- **12V 固定のアダプタ**では 12V の出力を保証しない。動いている最中の過電圧はファームウェア頼み
- **12V の短絡**は、F1 が切れるまで Q1 を入れたままにするファームウェアの手順に頼っている (ハードで速く切る回路は無い)
- **Q1 の立ち上がりと挿した瞬間**はシミュレーションだけ
- **過電圧の遮断のしきい値**は計算だけ。ツェナーの小さい電流での電圧は見積もり
- **ブリーダの熱いときの余裕**は、SS54 の逆電流の typical の線に対するもの
- **部品の極性とピンの並び**は、JLCPCB (EasyEDA) のシンボルを信じている
- **ブラケットの寸法は推定**。1 番ピンからブラケットまでが違えば、USB-C の口とブラケットの面がずれる
- **J3 は JLCPCB が両面とも手はんだで付ける** (サポートの回答)。手はんだの追加料金と治具が要るかは、発注の前の審査で決まる ([製造](manufacturing.md#j3-基板の端をはさむスロット-の注意))
- **うらの GND の東西のつながり**は、帯の北の通り道 (幅 約 3.6mm) と帯の下の溝 (約 0.9mm) の 2 か所だけ。検査 `groundPlane` は 1 枚であることだけを見る
