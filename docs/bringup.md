## 発注の前に

実物のカードで寸法を測る ([実物で測る所](mechanical.md#実物で測る所))。見積もりの画面で確かめることは [manufacturing.md](manufacturing.md#見積もりの画面で見る所)。

## 最初に測ること

カードを挿す前に、カードなしで順に見る。② につなぐ充電器は、**壊れてもよいもの**を使う (立ち上げで回路に誤りがあれば、充電器の側も巻き込むおそれがある)。

1. ② だけをつなぐ: 3.3V も 12V も出ないこと
2. ① をつなぐ: 3.3V が出ること (LED3 が光る)。マイコンが空のあいだは 12V が出ないこと
3. ファームウェアを書き込む (J5)。12V が出ること、PERST# が遅れて上がること
4. 充電器を挿した瞬間に +12V の線が動かないこと
5. ここまで通ってから、カードを挿す
6. **ケーブルの向きを確かめる。** 両端 PH 4 ピンのケーブルが「同じ向き (1 → 1)」であること (テスターで両端の 1 番どうしが導通するか)。市販の PH ケーブルは D+ と D− を撚っていない (USB のケーブルとしては作られていない) ので、HS で不安定なら撚ったものに替えて比べる。カードを挿す前に、J4・J6 の 1 番 (VBUS) に 5V、4 番が GND であることを測る
7. **カードをつないだ状態で、カード 2 台の VBUS の電流 (JP3 の橋を切って測るか、ケーブルの VBUS の線で測る) と、U9 の出力 (C38) と F2 の先 (J4・J6 の 1 番) の電圧、U9 の温度を測る。** U9 には過熱の保護が無い。9V の入力で 2 台が 20mA を大きく超えたら、rev E で U9 を過熱の保護つきの LDO に替える ([カードの VBUS](design.md#カードの-vbus-u9))
8. **J1 を挿した瞬間の電流** (VBUS1。電流のプローブか、ケーブルに直列の小さな抵抗で、シングルショット)。D1 の先の VIN のコンデンサ (約 100µF) と C38 が一度に充電されるので、USB 2.0 の突入の決まり (10µF・50µC 相当) を超える。PC の口が切れないか、何回か挿して見る ([カードの VBUS](design.md#カードの-vbus-u9))
9. **ハブ (U8) が PC から見えるか、カード 2 台が High-Speed (480Mbps) で見えるか** (`lsusb -t` で 480M、`lsusb -v` でハブが自己給電かバス給電か)。`lsusb -t` で**ハブが 2 段になるか**も見る (カードの中にもハブがあるかもしれない。あれば U8 の下にもう 1 段のハブが出る)
10. **8 チャンネルの同時受信** (2 台 × 4) で、ドロップやエラーが出ないか。ハブの上りは 480Mbps を 2 台で分ける
11. **J1・J2 の抜き差しのときの VBUS のピーク** (VBUS1・VBUS2) をオシロで測る (シングルショット、何回か)。ケーブルのインダクタンスと口のコンデンサで、挿した瞬間に跳ねることがある。**30V に近ければ TVS を考える** (いまは VBUS に TVS が無い)
12. ノイズとドロップを、USB のアイソレータの有り無しで比べる ([USB の GND のループ](#usb-の-gnd-のループ))
13. **ハブの水晶 (Y1) の周波数**を周波数カウンタで測る。U8 の XO (1 番) の側に、容量の小さいプローブ (10:1 など) を当てる (プローブの容量で少し低く出る)。Y1 は負荷容量 20pF で、CH334P の中の 約 10pF に合っていないので、12MHz より数十 ppm (数百 Hz) 高い見込み。**USB の許容の ±500ppm (12MHz ± 6kHz) を超えるか、それに近ければ 12pF の C70565 に替える** ([Y1](parts.md#y1))
14. **ハブ (U8) の電源の電圧**を、カード 2 台が動いている (8 チャンネルを受信している) 状態で測る。U8 の VDD33 (16 番。C35 の 1 番で測る) の平均の電圧と、カードの負荷が変わるときの落ち込み (オシロ、AC 結合) を見る。
    CH334P の低電圧のリセットのしきい値は 2.5〜3.2V (標準 2.9V)、外から入れる 3.3V は 3.2〜3.4V (CH334 のデータシート V2.4 の表 4.2 の読み)。+3V3 は公称 3.307V で、カードの 3A と同じ線なので、余裕は 0.1V ほどしかない。
    落ち込みが 3.2V を割るなら、ハブが切れて付き直すおそれがある (受信中に `dmesg` に USB の切断が出ないかも見る)。割るなら、C36 を大きくするか、rev E でハブの電源をカードの 3.3V から分ける

測る点は TP1 (VIN)・TP2 (+3V3)・TP3 (+12V)・TP4 (+5V、マイコン)・TP5 (GND)。カードの VBUS は C38 か J4・J6 の 1 番で測る。電流は JP1・JP2 で測る ([届いてから手ですること](manufacturing.md#届いてから手ですること))。

## USB の GND のループ

受信のノイズやドロップが、GND のループから来ていないかを比べる。

- **ループの最有力 (推定)**: アンテナの同軸 → カード → 基板 (J3 の GND) → J1 → USB ケーブル → PC の筐体。アンテナの側と PC の側が別の所で接地されていると、この輪に電流が流れる
- 比べ方: PC と J1 の間に**外付けの HS (480Mbps) の USB アイソレータ** (例: 東京デバイセズ TDPC2011、DSD TECH SH-G01L) を挟んだときと、挟まないときで、次を比べる
  - 受信のドロップ (8 チャンネルの同時受信。[最初に測ること](#最初に測ること) の 10)
  - ノイズ (受信のレベル・C/N・エラーの数)
  - `lsusb -t` の速度が 480M のままか (HS を通さないアイソレータだと 12M に落ちる)
- **挟むと、J1 から PD は取れない。** アイソレータの出口は 5V・300mA 程度 (製品による) で、9V は来ない。基板の電源は J2 の充電器 (PD で 9V を出すもの) から取る。充電器が 5V しか出さないと、D1 と D2 の両方から VIN へ流れ、J1 の側の 300mA を超えるおそれがある
- J1 の VBUS1 から直に取るものは、300mA の中に収まる必要がある: **U9 (カード 2 台の VBUS。VBUS1 から取る、100mA まで)**、ブリーダ (5V で 5mA)、U1 (CH224A)、U3 の EN と検出の分圧。ハブの U8 は +3V3 (VIN からの降圧) から取るので入らない
- 充電器が接地つき (3 ピン) だと、充電器の側にも別のループができる。比べるときは接地の無い充電器を使う

絶縁を基板に入れる案は [history.md](history.md#次の版の候補)。

## 確かめていないこと

回路について、計算やデータシートの読みだけで決めている所。試作で分かる。

- 実際の電気的な動作、発熱、PD の相手ごとの振る舞いは、何も確かめていない
- **D1・D2 の熱**: 熱抵抗は計算できていない。5V・3A は危ない見込み
- **CH224A の CC の入れ替え**は、データシートの記述からの判断
- **CH224A**: DP/DM を浮かせてよいか、PG を浮かせてよいか、I2C のプルアップの電圧は、データシートに書かれていない
- **12V 固定のアダプタ**では 12V の出力を保証しない。動いている最中の過電圧はファームウェア頼み
- **12V の短絡**は、F1 が切れるまで Q1 を入れたままにするファームウェアの手順に頼っている (ハードで速く切る回路は無い)
- **Q1 の立ち上がりと挿した瞬間**はシミュレーションだけ
- **過電圧の遮断のしきい値**は計算だけ。ツェナーの小さい電流での電圧は見積もり
- **ブリーダの熱いときの余裕**は、SS54 の逆電流の typical の線に対するもの
- **部品の極性とピンの並び**は、JLCPCB (EasyEDA) のシンボルを信じている
- **カードの内部 USB のピンの割り当て** (1 VBUS・2 D−・3 D+・4 GND) は、元のケーブルの線の色からの推定 ([内部 USB のコネクタ](design.md#内部-usb-のコネクタ))。違えば `lib/card-usb.ts` を直す
- **VBUS の抜き差しのときの跳ね**: VBUS1・VBUS2 に TVS は無い。ピークは測っていない ([最初に測ること](#最初に測ること) の 11)
- **CH334P の水晶のランド**は EasyEDA のまま (データシートと照合していない)。底の板の穴にはんだが吸われないか
- **ハブの電源の余裕**: U8 はカードと同じ +3V3 で動く。低電圧のリセットのしきい値 (最大 3.2V) までの余裕は 0.1V ほどで、カードの負荷が変わるときに割らないかは測っていない ([最初に測ること](#最初に測ること) の 14)
- **水晶の負荷容量**は合っていない (水晶 20pF、CH334P の中は 約 10pF の見込み)。ずれは数十 ppm の推定で、測っていない ([最初に測ること](#最初に測ること) の 13)
- **ブラケットの寸法は推定**。1 番ピンからブラケットまでが違えば、USB-C の口とブラケットの面がずれる
- **J3 は JLCPCB が両面とも手はんだで付ける** (サポートの回答)。手はんだの追加料金と治具が要るかは、発注の前の審査で決まる ([製造](manufacturing.md#j3-基板の端をはさむスロット-の注意))
- **うらの GND の東西のつながり**は、帯の北の通り道 (幅 約 3.6mm) と帯の下の溝 (約 0.9mm) の 2 か所だけ。検査 `groundPlane` は 1 枚であることだけを見る
